Notification message builder

Add Survsys.Api/NotificationMessageBuilder.cs: a scoped class over SurvsysDbContext with Build(int personConditionId, string processingId, DateTimeOffset at, CancellationToken) returning the generated message (null when an error-severity message stops it), the guide id, and the list of (PhinVar, Message, Severity) the formatters raised. It loads the case into an EpiTraxRecord (case fields plus the Lab, Vaccine, Treatment and Travel datasets), builds the PhinVariableCatalog from the reference tables, maps the case's condition with PhinVariableMapper, loads each variable's rule set config into a LoadedRuleSet, picks the formatter by rule_set label, runs repeating-group variables through RepeatingGroupProcessor, and generates with OruR01Generator using a header built from the existing CDC/sending configuration and the processing id given. A variable with no rule set or an unknown label is reported as a warning, not thrown. Register it in Program.cs.
